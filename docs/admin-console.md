# 后台控制台

后台入口为 `/admin/`，只在 `npm run dev` 下具备读写能力。生产产物中的后台是只读静态壳，`/api/admin/*` 一律返回 404。导航包含概览、主题、写作、图片、快照，路由定义在 `src/lib/admin-console/routes.ts`。

## 概览

汇总内容规模、标签分布、字数与最近条目，读取各集合的已发布条目与草稿数量。开发环境下显示维护者视图（含草稿）；生产环境按 `site.json` 的 `adminOverview.publicVisible` 决定是否输出公开版本，关闭时显示 `adminOverview.hiddenMessage` 的文案。

## 写作

内容管理控制台，覆盖 `blog`、`projects`、`bits`、`devlog`、`about` 五个集合。各集合的能力矩阵定义在 `src/lib/admin-console/content-collections.ts`。

| 能力 | 说明 |
| --- | --- |
| 新建与编辑 | 按标题生成 `YYYY-MM-DD-title` 形式的条目 ID，写入对应集合目录 |
| 草稿状态 | 切换 `draft`，列表可据此筛选 |
| 正文编辑 | 开发环境挂载 Markdown 编辑器，支持插入图片、图库与公式 |
| 列表操作 | 按集合与草稿状态过滤、排序、正文搜索、分页、批量改状态与批量导出 |
| 删除 | 按集合能力开放，固定页面（`about`）不支持删除 |

各集合的差异：`blog`、`projects`、`devlog` 支持正文图片上传与图片选择器；`bits` 只支持图片选择器，正文不插入图片；`about` 只编辑固定单页正文，不能新建、删除或切换草稿。

| 集合 | 新建 | 删除 | 草稿 | 正文图片上传 | 图片选择器 |
| --- | --- | --- | --- | --- | --- |
| `blog` | 是 | 是 | 是 | 是 | 否 |
| `projects` | 是 | 是 | 是 | 是 | 是 |
| `bits` | 是 | 是 | 是 | 否 | 是 |
| `devlog` | 是 | 是 | 是 | 是 | 是 |
| `about` | 否 | 否 | 否 | 否 | 否 |

编辑页按 `[collection]/[edit]/[...entryId]` 组织，`/admin/content/` 为列表与批量操作入口，对应 API 在 `src/pages/api/admin/content/`。固定页面（关于）的正文只有一份，标题与副标题的覆盖值来自 `page.json`。

## 图片

浏览 `public/`、`src/assets/`、`src/content/` 与云端来源下的图片，分组为全部、各集合、配置素材、页面插图、云端图片与未归类，可按最新修改筛选。

| 操作 | 说明 |
| --- | --- |
| 上传 | 内容配图写入 `public/images/{collection}/{slug}/`，`{slug}` 为条目 ID |
| 重命名 | 改名的同时同步引用，避免正文指向不存在的文件 |
| 元信息 | 读取尺寸、来源与所属集合，供选择器与列表展示 |
| 站点资源上传 | favicon 等站点级资源走独立接口 |

列表与筛选状态体现在 URL 查询参数（`group`、`scope`、`sub`、`q`、`page`），可直接分享链接。云端来源需要配置对象存储凭据，逻辑在 `src/lib/admin-console/image-cloud-storage.ts`。

## 主题

编辑全部主题设置，分组与 `src/data/settings/` 的五个 JSON 文件一一对应。

| 分组 | 主要字段来源 |
| --- | --- |
| 站点设置 | `site.json`：站点标题与窄屏标题、站点描述、站点语言、页脚版权、备案信息、favicon、社交链接、后台概览可见性、窄屏标题宽度上限、页面外缘间隙 |
| 侧栏 | `shell.json`：站点名与引用文案（支持限定的富文本）、导航标签、装饰符、顺序与可见性 |
| 首页 | `home.json`：引导语、更多入口链接、Hero 图与替代文本 |
| 内页设置 | `page.json` 与 `ui.json`：各列表页标题与副标题、列表页 RSS 开关、动态页默认作者、代码块行号、阅读模式入口、浮动操作列、浏览数据、侧栏动作、文章元信息、侧栏分隔线与字体角色 |

保存走 `/api/admin/settings`，写入前校验字段并给出变更预览。开发环境下修改字体角色需要重启开发服务器。

侧栏导航与社交链接的条目支持拖拽排序：抓住该行最右侧的拖动锚点上下拖动即可，也可以聚焦锚点后用方向键移动。放下后序号按新顺序重写为 1..N。

## 快照

导出与导入设置快照，用于迁移或备份。导出内容为 `settings` 作用域，不包含内容、图片与凭据，包结构含 `schemaVersion`、生成时间与排除项清单，接口为 `src/pages/api/admin/data/settings.ts`。

## 常见操作路径

| 目标 | 路径 |
| --- | --- |
| 新建一篇博客 | `/admin/content/` → 选博客 → 新建 |
| 改站点标题或备案号 | `/admin/theme/` → 站点设置 |
| 开关浏览数据或浮动按钮 | `/admin/theme/` → 内页设置 |
| 替换首页 Hero 图 | `/admin/theme/` → 首页，或在 `/admin/images/` 上传后选择 |
| 批量删除草稿 | `/admin/content/` → 按草稿筛选 → 选中条目 → 批量操作 |
| 迁移到另一台机器 | `/admin/data/` → 导出快照，在新环境导入 |

## 写入流程

写入分为三类：主题设置写入 `src/data/settings/*.json`，内容写入 `src/content/**`，图片写入 `public/**` 或云端存储。请求带版本标识，服务端在写锁内校验版本与字段，通过后以文件事务方式落盘并清理相关缓存，避免并发保存互相覆盖。

设置文件损坏（JSON 非法、根节点类型错误或字段不合法）时，控制台进入只读状态并列出需要修复的文件与字段，不再接受保存；手改 JSON 引入的个别非法值不会锁住后台，读取时按默认值兜底。

## 开发环境边界

可写能力由构建输出模式区分：开发环境为 `server`，写入接口可用；生产构建为 `static`，后台页面输出静态只读壳。`npm run check:prod-artifacts` 在产物上断言后台各页面不含写入相关的界面标记，且不输出导航入口。

开发环境使用的界面偏好（顶部导航可见性、侧栏导航模式、编辑器默认布局）保存在浏览器 localStorage，不写入仓库文件。
